## Cafes API – RESTful API for Café Management

* Developed a RESTful API using Python and Flask to manage and retrieve café information stored in an SQLite database.

* Implemented endpoints to retrieve all café records, obtain random café recommendations, and search for cafés by location.

* Built CRUD-related functionality supporting café registration, price updates, and record deletion through HTTP methods such as GET, POST, PATCH, and DELETE.

* Integrated Flask-SQLAlchemy and SQLAlchemy ORM to manage database operations and data persistence.

* Implemented API key validation to restrict café deletion operations and prevent unauthorized requests.
